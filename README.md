# haisyoku-system

配食業務用VBA/Excelシステム（野田市・春日部市エリア）

## システム一覧

| フォルダ | システム名 | 概要 |
|---|---|---|
| route/コース設定 | 仕分けルート別一覧表 | ルートごとの配達先・回収列管理 |
| meal/食事提供管理 | 食事提供管理 | 食数集計・調理指示表生成 |
| meal/調理指示照合 | 調理指示照合マクロ | 嫌いなもの一覧表との差異チェック |
| customer/水色マーキング | 水色マーキングシステム | 野田市配食対象顧客のハイライト |
| customer/配布管理 | 配布管理システム | メニュー配布リスト・重複防止 |

## 管理方針

- VBAモジュールは `.bas` ファイルにエクスポートしてGit管理
- `.xlsm` 本体はバイナリのため除外（ローカル管理）
- 仕様メモ・運用手順は `docs/` に記載
